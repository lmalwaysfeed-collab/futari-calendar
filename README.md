# ふたりカレンダー（Discord bot）

Discordだけで、ふたりの予定を共有するbotです。Googleカレンダーなどは使いません。
見た目は水色の韓国ガーリーテーマ（ギンガムチェック・リボン・マスキングテープ）です。

## 予定の入れ方（いちばん楽な順）

1. **予定チャンネルに書くだけ**
   `明日19時 ごはん` と書けば、それで登録されます
2. **botにメンション**（どのチャンネルでもOK）
   `@ふたりカレンダー 土曜 水族館`
3. **🎀「予定を追加」ボタン**（カレンダーや朝のお知らせに付いています）
   押すと入力欄が出るので、1行書くだけ
4. **`/よてい`** コマンド

書き方の例：

| 書いた文章 | 登録される予定 |
|---|---|
| `明日19時 ごはん` | 明日 19:00〜21:00 ごはん（ふたり） |
| `土曜 13時半〜17時 水族館デート` | 今度の土曜 13:30〜17:00 |
| `あさって 9時 バイト けんくん` | あさって 9:00〜 バイト（けんくん） |
| `来週の金曜 夜8時 通話` | 来週金曜 20:00〜 |
| `10/31 ハロウィン` | 10/31 終日 |
| `今週末 おでかけ` | 今度の土曜 終日 |

- 「けんくん」「ゆい」など名前を書くとその人の予定、「ひとり」「じぶん」なら自分の予定、何も書かなければ **ふたりの予定** になります
- 日付を書き忘れたら「いつ？」と聞かれるので、ボタンで選ぶだけ
- 登録したあとに出る **🩵ふたり／💜ゆいちゃん／🤍けんくん** ボタンで、だれの予定かをワンタップで切りかえ。**取り消し** もワンタップ

## 見てわかる表示

- **月のカレンダー画像**：🩵 空色＝ふたり　💜 ラベンダー＝ゆいちゃん　🤍 ミルク＝けんくん
  今日はマスキングテープと丸印、記念日にはハートのシール。◀ ▶ で月を移動
- **毎朝の1週間予定表**（画像）と、次のデートまでのカウントダウン
- **空いてる日**は点線のマスに「あいてる ♡」
- 予定の **1時間前** にメンションでお知らせ
- 追加した予定は、サーバーの **イベント欄** にも自動で載ります

## コマンド

| コマンド | できること |
|---|---|
| `/よてい` | 1行で予定を追加 |
| `/カレンダー` | 月のカレンダー画像（月:`11` で11月） |
| `/これから` | これから1週間の予定表 |
| `/予定削除` | 予定を消す（候補から選ぶだけ） |
| `/空いてる日` | ふたりとも予定がない日 |
| `/記念日` | 付き合って何日目か |
| `/設定` | チャンネル・相手・記念日・朝の時刻 |
| `/サーバー` | 仕訳バトルのサーバーを起動・停止（ボタンで操作） |
| `/みる` | SyncTube のお部屋を開くボタンを出す |
| `/お題` | お題ガチャ（`追加:` でお題をこっそり入れる） |
| `/ワンドロ` | お題でワンドロのタイマーをはじめる |
| `/作品` | 作品をギャラリーに入れる（ワンドロ中なら提出） |
| `/ギャラリー` | 月ごとの作品をチェキ風に並べて見る |
| `/成長` | はじめのころと最近の作品を並べて見る |

## はじめの準備（1回だけ）

### 1. botを作る

1. https://discord.com/developers/applications →「New Application」→ 名前（例: ふたりカレンダー）を入れて作成
2. 「General Information」の **Application ID** をコピーしてメモ
3. 左メニュー「Bot」
   - 「Reset Token」→ 出てきた **Token** をコピーしてメモ（他人に見せないこと）
   - 下の方の **「Message Content Intent」をオン** にして保存（書くだけで登録する機能に必要です）

### 2. 設定ファイルを作る

このフォルダの `.env.example` をコピーして名前を `.env` にし、メモした2つを書き込んで保存。

### 3. インストール

このフォルダでターミナルを開いて：

```
npm install
```

### 4. サーバーに招待

```
npm run invite
```

表示されたURLをブラウザで開いて、ふたりのサーバーを選んで「認証」。

### 5. 起動

```
npm start
```

`ふたりカレンダー起動` と出ればOK。PCを付けている間、botが動きます。

### 6. Discordで最初の設定

予定を書くためのチャンネル（例: #よてい）を作ってから：

```
/設定 予定チャンネル:#よてい 通知チャンネル:#よてい あいて:@けん わたしの呼び名:ゆいちゃん あいての呼び名:けんくん 記念日:2025/7/12
```

- コマンドを打った人が 💜、あいてが 🤍 になります
- 呼び名を入れておくと、カレンダーに名前が出て、文章に「けんくん」「けん」と書くだけでその人の予定になります
- 朝のお知らせは8時。変えたいときは `朝の時刻:7` のように入れます

## 創作（お題ガチャ・ワンドロ・ギャラリー）

**お題ガチャ**：`/お題` で回すと、お題が出ます。★★★ のレアお題は2つの組み合わせです。**ひみつのお題**：`/お題 追加:ふたりの秘密基地` か、ガチャの「🤫 こっそり追加」ボタンで、お題をこっそり入れられます。返事は入れた本人にしか見えないので、相手にはガチャで出るまでないしょです。出たときに「💌 〇〇がこっそり入れたお題だよ！」と正体がわかります。まだ出ていないお題から優先して出ます。

**ワンドロ**：ガチャの「これで60分ワンドロ」ボタンか `/ワンドロ` ではじまります。
- 残り10分と終了のときにお知らせが来ます
- 提出は、そのチャンネルに画像を貼るか `/作品` で。ふたりとも出したら、並べた結果カードが届きます
- 終わってから30分は「ちょっと延長」で提出できます

**ギャラリー**：作品は次の3つの方法でたまります。どれもPCの `gallery` フォルダに保存されます。
- `/設定 作品チャンネル:#作品` にしたチャンネルに画像を貼る（いっしょに書いた文字がタイトルになります）
- `/作品` で画像を送る
- ワンドロで提出する

`/ギャラリー` で月ごとのチェキ風コラージュ、`/成長` で最初と最近の作品のビフォーアフターが見られます。月のはじめには、先月の作品まとめが自動で届きます。

## SyncTube をすぐ開く

```
/設定 synctube:https://sync-tube.de/rooms/(お部屋のID)
```

一度登録すると：
- `/みる` で「🎬 SyncTube」ボタンが出ます
- ふたりのどちらかがボイスチャンネルに入ると、通話のチャットに自動でボタンが出ます（30分に1回まで。`/設定 通話でボタン:False` でオフ）
- カレンダーや朝のお知らせの下にも、SyncTube ボタンが並びます

## 仕訳バトルのサーバーもDiscordから動かす（/サーバー）

`/サーバー` を打つと操作パネルが出ます。

- **▶️ 起動**：仕訳バトルとトンネルをまとめて起動し、**URL Mappings に貼るURL** を表示します
- **⏹️ 停止 / 🔄 再起動**
- **👀 更新**：いまの状態（動いてる / 止まってる）を見る
- **📄 ログ**：うまく動かないときの原因を見る（自分にだけ表示）
- **🎀 このbotを再起動**：下の「自動起動」で動かしているときだけ出ます
- 仕訳バトルが予定外に止まったら、パネルを出したチャンネルにお知らせが来ます
- 操作できるのは `/設定` のふたりだけです

使う前に `.env` に、仕訳バトルのフォルダの場所を書いておきます。

```
SHIWAKE_DIR=C:\Users\あなたの名前\Documents\shiwake-battle
```

`AUTO_START_SHIWAKE=1` にすると、botが起動したときに仕訳バトルも自動で起動します。

※ 無料のトンネルは起動するたびにURLが変わるので、そのたびに Developer Portal の URL Mappings を貼りかえる必要があります（パネルにコピーしやすい形でURLが出ます）。

## PCをつけたら、ログインしなくても裏で動かす（おすすめ）

1. このフォルダの **`service-on.bat`** を右クリック →「**管理者として実行**」
2. パスワードを聞かれたら、Windowsのパスワードを入れる（PINでログインしている人は、Microsoftアカウントのパスワード）
3. 「OK」と出たら完了

これで、PCの電源を入れて1分たつと、だれもログインしていなくてもbotが裏で動きます。サインアウトしたり、ほかのアカウントに切りかえたりしても止まりません。画面は出ないので、記録は `bot.log` で見られます。やめたいときは `autostart-off.bat` です。

## PCをつけたら自動でbotを起動する（ログインしたときだけ）

1. このフォルダの **`autostart-on.bat`** をダブルクリック
2. 「OK」と出たら完了。次からはPCにログインするだけで、画面に出ずにbotが動きます
3. botが止まっても、10秒後に自動で起動し直します

やめたいときは **`autostart-off.bat`** をダブルクリック。

※ PCがスリープしている間はbotも止まります。ずっと動かしたいときは、Windowsの「電源とスリープ」でスリープを「なし」にしてください。

## アップデート（ボタン1つで新しいバージョンにする）

`.env` に GitHub のリポジトリを書いておくと、`/サーバー` のパネルに **⬆️ アップデート** ボタンが出ます。

```
UPDATE_REPO=あなたのGitHubユーザー名/futari-calendar
```

押すと、新しいバージョンがあればダウンロードして入れかえ、botを再起動します。
`.env`・`data.json`（予定と設定）・`bot.log` は上書きされません。

## よくあること

- **「時間内に応答しませんでした」と出る** … 古いbotが動いたままかもしれません。`autostart-off.bat` で全部止めてから、もう一度起動してください。`/サーバー` の下に出るバージョン（v1.4 以上）で確認できます

- **書いても反応しない** … Developer Portal の「Message Content Intent」がオンか確認して、botを起動し直してください（オフだとコマンドとボタンだけで動きます）
- **コマンドが出てこない** … Discordを再起動（Ctrl+R）してみてください
- **イベント欄に載らない** … 招待のときの権限に「イベントの作成」が入っているか確認。過去や1分以内の予定は載りません
- **画像の文字が四角になる** … `.env` に `FONT_FILE=C:/Windows/Fonts/meiryo.ttc` を足してください

予定は同じフォルダの `data.json` に保存されます。消すと予定もなくなるので注意。

## ファイル構成

```
bot.js      bot本体（入力・ボタン・朝のお知らせ・リマインド・サーバー管理）
servers.js  仕訳バトルとトンネルの起動・停止
art.js / art-render.js  お題ガチャ・ギャラリーのデータと画像
gallery/    保存した作品（アップデートしても消えません）
start-bot.bat / service-on.bat / autostart-on.bat / autostart-off.bat  自動起動まわり
render.js   カレンダー画像のデザイン（色やかざりはここ）
views.js    予定 → 画像の中身
image.js    画像をPNGにする
pictures.js / render-worker.js  画像づくりを別の場所でやる（botが固まらないように）
lib.js      文章・日付の読み取り
store.js    data.json への保存
```
